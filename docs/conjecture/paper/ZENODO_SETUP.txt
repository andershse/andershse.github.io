Zenodo deposit setup
====================

This deposit is optional for initial IEEE Control Systems Letters
submission. The current paper offers the code from the author on request
and contains all main proofs. Zenodo connection problems need not delay
submission of the manuscript PDF.

Prepared
--------
  identifiability-verification.zip  The public software payload
  zenodo_metadata.json             Title, author, affiliation, description,
                                   version 1.0.0, open access, MIT license
  zenodo_deposit.py                Preview, draft upload, or publication

The archive contains only verification code, exact outputs, dependencies,
documentation, citation metadata, a license, and a checksum manifest.
The manuscript, private referee report, and local account data are excluded.
The paper will cite the software automatically once its public DOI exists.

Account step
------------
There is no connected Zenodo plugin in this session. Automatic approval
review rejected launching the interactive browser session, reporting only
"blocked by policy." No account or public record was created.

1. Sign in to, or create an account at, https://zenodo.org/
2. Create a personal access token at:
   https://zenodo.org/account/settings/applications/tokens/new/
   Select deposit:write and deposit:actions.
3. Run the uploader below in your own PowerShell terminal. Enter the token
   only in its hidden prompt. It is sent in HTTPS headers and is not saved
   in the archive, source files, or local state file.

Review the files and metadata
----------------------------
From C:\Users\andha17\Documents\Code\conjecture:

  .\.venv\Scripts\python.exe .\paper\zenodo_deposit.py preview

This is offline and makes no changes to Zenodo. In particular, the metadata
proposes an MIT license for the code. The license text is in
paper\verification\LICENSE.

Upload and publish the prepared release
---------------------------------------
After reviewing the preview, run:

  .\.venv\Scripts\python.exe .\paper\zenodo_deposit.py publish

This creates the deposit under your account, fills its metadata, uploads
the archive, checks the server's file checksum, and publishes the software.
It then verifies the public record and writes paper\verification_doi.tex.
Running the same command again resumes the same draft or retrieves the
existing public record rather than creating a duplicate.

To create an unpublished draft instead, use the action "draft".

After publication, compile the manuscript with:

  Set-Location .\paper
  pdflatex -jobname=local_global_identifiability_submission -interaction=nonstopmode -halt-on-error local_global_identifiability.tex
  pdflatex -jobname=local_global_identifiability_submission -interaction=nonstopmode -halt-on-error local_global_identifiability.tex

The public DOI will then appear in the software reference. Include
verification_doi.tex when distributing the paper's source.

Status and limitations
----------------------
The uploader has been checked locally, including its offline validation and
simulated draft/publication paths. A live upload requires your account and
has not yet been tested or performed. A DOI is inserted only after the
public record is retrievable from Zenodo.
